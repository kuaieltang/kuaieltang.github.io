01

认知篇

会议为什么重要？因为会议：

1.1

事关经营决策有效性

毫不为过地说，大约80%的重大经营决策都是在会议上做出的。

会议的议题设置是否合理，是否得到充分研讨，决策能否落实到位，不仅决定了会议的成败，甚至关系到正确决策能否做出，影响公司的生存和发展。

决策如何有效？德鲁克有一个非常重要的观点，值得铭记：管理者，首先要聚焦于机会，而不是解决问题。理由如下：

  • 解决问题，解决的只是企业内部的问题，但是企业的成果在外部（赢得市场的认可、客户的购买）。也就是说，解决问题并不必然产生成果；
  • 解决问题在本质上，只是一个效率改善的问题，是为了“正确的做事”，而企业首先要确保自己“做正确的事”；
  • 企业要取得成果，就必须发现和把握外部环境中的机会，把内部资源优先分配给机会。
1.1

机会导向，倒逼我们向外看

听起来很抽象，我打个比方就好理解了：现在你有一个问题，如果不解决，你会损失100块钱，你要不要解决？答案是不一定。如果在你解决这个问题的同时，你有一个可以从别人那里赚1000块的机会呢？你还会选择解决问题吗？

“损失100块”是自己的事、是内部的事，是萦绕在你心头的“问题”；而从别人那里“赚到1000块”则是外部的事，是取得成果的“机会”，所以机会导向，倒逼我们向外看、向成果看。而不是孜孜于解决问题——很多问题不值得解决。

任正非说：企业经营宛如滚滚长江，在奔腾入海的过程中，必然伴随着泥沙俱下，有问题很正常。只要在正确的目标牵引下滚滚向前，过程中的问题都将不再成为问题。但我们也会看到，现实中一些管理者好像天生有“洁癖”，整天拿着显微镜找问题，舍本逐末。企业很多问题是过程性和阶段性的，无须解决却非要解决就是做无效功。
1.2

事关成本和效率

会议的直接成本是巨大的。粗算一笔：一场10个人2小时的例会，直接消耗 20 个工时，即便按照时薪100元计算，也高达2000元。随心所欲、毫无目标地开会，相当于无声的烧钱。

会议的机会成本也是巨大的。人们在开会的时候，就做不了其他工作，也就是说会议本身并不产生成果，只有会议的决策在会后得到了落实，才能产生真正的成果。

除此之外，浪费时间的现象也触目惊心。广告界有句话：我知道我有一半的广告费浪费了，但不知道是哪一半。会议就像广告，有一半时间浪费在看不见的地方：等待迟到者、跑题发言、情绪化争执……。

成本大不是问题，问题是成本必须取得相应的成果。会议必须卓有成效，否则就无法匹配其成本。会议不必“圆满结束”，而要“满载而归”。
1.3

事关企业文化和领导力

开会是集体活动，影响到所有参会者。会开得怎么样，事关企业文化的塑造。会开得怎样，企业文化就是怎样的。会议，是展现、检验和塑造企业文化的重要时刻。

领导在会议中发挥重要角色。领导能否对会议取得预期成果负起责任，能否在决策过程中展现开放、包容、理性、务实的态度，能否以身作则直面问题、挖掘机会，对参会者影响重大。可以说，会议，还是管理者发挥领导力的最佳时刻。

小结

总而言之，每家教培机构都要认识到会议的重要性，对会议进行通盘考虑、整体规划和顶层设计，建立和完善高效会议体系，本质上是：

  • 将公司的重大决策匹配到重要会议，确保决策有抓手，会议有成果。
  • 对会议做专项时间预算，减少时间浪费，让成本产出成果；
  • 从会议抓起，让企业文化“活”在日常，让领导力得到发挥。

一句话：高效会议体系，是把会议常见的“问题”，转变为聚力增效的“机会”，实现：少开会、开好会，开出成果、开出精神。

有体系地开会，是一个成熟公司的表现。

02

规划篇

从时间预算出发，控制会议总时长；再从经营决策的需要出发，给一个经营周期做好会议的整体规划。

2.1

从时间预算出发，控制“会议总时长”

关于时间管理，绝大多数人的思维是“为任务分配时间”：我有这些任务要完成，必须要给它们分配时间，塞进日程表里。其结果，就是日程表满满当当，忙得不可开交，但是否“卓有成效”呢？未必。这种做法，其隐含前提是，所有任务都必做，因此必须在日程表获得一块时间。

德鲁克式的时间管理，则完全相反。他指出，时间是最宝贵的资源。与金钱、人力或设备不同，时间租不到、借不到、买不到、极其稀缺、毫无弹性且无法储存，所以我们必须“为时间匹配任务”。我们必须问，什么样的任务配得上如此宝贵的时间？只有那些最重要、最能产生成果的任务，才配得上。所以我们必须把大块的时间，优先分配给这些任务，才能最大限度地产生成果。

普通的时间管理，会让我们“塞满日程”，忙而低效；而德鲁克式的时间管理，会倒逼我们“做出取舍”，卓有成效。

会议是公认的时间杀手，我们必须对会议进行“时间管理”。建立高效会议体系，就是以全面的“时间预算”，用德鲁克式的办法来管理会议。

我们必须严控“会议总时长”（因为前面说过，开会本身是不会产出任何成果的，会后的行动才会）。

要为做出“重大经营决策”的会议，优先安排会议时长。

只有那些最重要、最能产生成果的任务，才配得上宝贵的时间——会议也不例外。
2.2

从经营决策的需要出发，整体设计

国家有5年计划。围绕五年计划的制定，要召开很多会议，会议成果最终体现在其中。

每个培训机构，也都有其经营周期（如一年）。在经营周期内的某个时间节点，必须要做出某些重要决策。

例如：我以前担任总校长的机构，其经营周期为：每年7月至次年6月。于是，6月底之前我们必须做出下一年度的预算。而要做出预算，就必须制定下一年度的年度计划（含经营目标）。而下一年度的年度计划，又必须依据未来三年的三年计划。这是把机构的发展战略落实到经营中的关键：用长期计划来指导短期计划，把短期计划变成日常经营行为。

所以，我们会把这些决策落到重要会议中，形成了一个由宏观战略到日常经营的会议体系：

注｜该机构有总部和8所分校。总部设人力行政部、财务部、教研院；分校以区域为单位划分，负责招生、教学，独立核算。
2.2

一个经营周期的会议体系

战略研讨会

在4-5月开会，回顾去年制定的三年规划的落实情况，讨论决定未来三年计划（即滚动计划）。

年度计划研讨会

在5月底，基于三年计划，开会决定我们下一年度的年度计划。年度计划会后，总部各部门和各分校，分头做下一年度预算，6月底提交，经总校长和董事长批准后执行。

经营分析会

每月召开经营分析会，对照年度预算和各项经营目标（如业绩目标、利润目标、教学教研目标、团队发展目标等）进行差异分析，找出问题，发现机会，制定具体的行动计划，落实到位。考虑到回顾的周期，我们对各月的会议定位为（注意经营年度是7月到次年6月）：

  • 7月 → “年度经营分析会”，回顾分析上一年全年度经营情况
  • 1月 → “半年度经营分析会”，回顾分析半年度经营情况
  • 4月、10月 → “季度经营分析会”，回顾分析上季度经营情况
  • 其他月份 → “月度经营分析会”，回顾分析上月经营情况
2.2

其他会议

年会

全公司年度总结表彰大会，每年一次，固定日期

专题会议

每年一次的“教学教研工作专题会”，时长1天
每年一次的“招生工作专题会”，时长1天
其他：经过研究决定增设的会议

以上就根据机构的情况，把一个经营周期（一年）内，最重要的会议，进行了整体规划。从经营决策的需要，对重要会议的必要性进行了论证，既保证了决策研究落实到会议，又有效地控制了会议的总量（增设会议必须经过研究讨论）。

特别说明：以上是整个机构层面的重要会议规划。分校内部、总部各部门内部的会议，由各分校、各部门按照类似的方法进行整体规划，整体原则：还是“少开会、开好会、开出成果、开出精神”。
2.3

不同类型的会议，其议题、需要做出的决策、产出的成果都是不同的，因此其频率、开会时长、参会人员、准备周期，都应该要区别对待，但又要做到（同类会议）标准化：

2.4

会议日程与经营年历

会议日程：我们在年度计划研讨会上，决定重要会议的具体日程（当然，会前由总部人力行政部提前研究，列出具体日程）。

然后由总部人力行政部，在企业微信内创建团队共享日程，并设置提前提醒（有些会议是提前一个月提醒，有些是提前一周），以便大家提前准备。

经营年历：在重要会议日程的基础上，我们又加入外部日历（如开学季、考试季、高考、重要节假日等）和全员活动，形成了一份“经营年历”。

经营年历 = 重要会议日程 + 外部重大事项日程 + 全员活动

03

执行篇

两个“二八原则”和“151原则”、主持人责权、会前会中会后，以及如何提高决策质量。

3.1

三个原则

我提出开会两个“二八原则”和“151原则”：

重准备

8分精力会前准备，2分精力会中决策。毛主席说，“调查研究是十月怀胎，解决问题是一朝分娩。”会前要充分调查、小范围研究。

重落实

2分精力会议决策，8分精力会后落实。德鲁克说：“决策如果没有明确的行动方案，便不能称为‘做了决策’，而是良好的意愿而已。”

具体执行层面，开会“151原则”：

  • 提前 1 天发出议题；
  • 提前 5 分钟到场；
  • 会后 1 小时内发出会议纪要。
3.2

明确主持人责权

会开不好，往往因为没有明确的责任人。明确会议的第一责任人是主持人——会议没开好，主持人首先要打五十大板。

（如果领导自己主持，更要注意。建议领导指定主持人，给年轻人创造锻炼机会）。

明确主持人的责任

  • 确保会议准时结束；
  • 引导参会者理性讨论、充分讨论；
  • 确保会议达到预期成果。

相应地，主持人应该有以下权力

  • 采取有力措施，维护时间纪律；
  • 掌控议程，让大家围绕议题发言，禁止跑题；
  • 维护议事规则，禁止打断别人、禁止人身攻击；
  • 约定每个人的发言次数和发言时间，超时提醒、打断发言。
成功的会议，需要这样的主持人：富有责任感、规则意识强、善于沟通。
3.2

时间纪律，就一条：禁止迟到

这一条，大家都没意见，关键是怎么落地？

  • 约定惩罚措施，迟到者乐捐，作为团建经费。领导首先要遵守这条。
  • 借鉴某些公司的做法：9:00 召开的会议，9:01 就把会议室的门从里面反锁——只要这样做一次，就可以使所有与会者今后都按时到场。
  • 迟到者错过了重要信息，不要重新开始或为他回顾会议内容。记住，迎合迟到者，实际上是在惩罚守时的人。
  • 每次会后复盘超时原因，提出整改措施。
3.3

会前准备

会前四件事：

  • 议题筛选：按 3.5 的原则筛选议题；
  • 明确目标：会议应该在什么时间开完？应该解决什么问题？拿到什么结果？
  • 明确流程：会有哪些环节，分别多长时间？
  • 发布通知：提前通知，确保参会人员知晓以上事项，做好准备；
记住：会前准备得越充分——事先有初步沟通、有初步方案、有提前发布议题，大家有思考和准备，流程越清晰——会议花费的时间就越少，会议就越高效。
3.4

会后落实

德鲁克说，决策必须包含执行，没有被执行的决策只是良好的意愿。

会后三件事：

  • 会后 1 小时内发出会议纪要。会议纪要本质上是个行动清单：决定了要做什么事（任务），谁去做（责任人）、什么时候完成（完成时限）。
  • 把会议结论告知需要知晓的人；
  • 复盘会议：会议是否达到预期目标？以后如何改进？
补充一点：下次会议，首先应该回顾和检查上次会议决策的落实情况，形成闭环。
还有句话：会议的结束，是工作的开始。
3.5

如何提高决策质量

管理学大师德鲁克说“最危险的事情并非给出错误的答案，而是提出了错误的问题”。很多会议之所以低效，一个重要原因，是因为问错了问题——讨论了不该讨论的议题。

我建议，会前应该仔细“筛选议题”，且领导应该参与其中。关于议题筛选，有三个原则：

  • 机会导向原则：如前所述，议题选择不能是“问题导向”，而应该是“机会导向”：什么行动，是取得成果的机会？我们做了什么样的事情，会带来很大成果？
  • 性质匹配原则：只讨论与本次会议性质（周期跨度）相符的议题。总校长不应该去拍板部门总监或分校校长应该拍板的事情。月度经营分析会不应该讨论年度计划研讨会议才讨论的问题——这些议题应该攒起来，放到年度计划研讨会上讨论。
  • 议题成熟原则：重大议题，如果没有事先酝酿、充分准备、形成初步方案，就不应该拿出来讨论。

提高决策质量的四条措施：

  • 议题应该是一条具体的、明确的、可操作的行动方案或行动建议；
  • 同一议题，让正、反两方充分辩论，分开表决（同意的、反对的分别表决）；
  • 要求发言人都对着主持人发言，防止情绪化发言、引发争吵；
  • 轮流发言，让每个人都有发言机会；

决策机制：民主集中制

先让大家轮流发表意见，（主持人请）领导最后拍板，拍板之后，不应再讨论。

（主持人应该在其他所有同事之后、在领导前，发表意见）

进阶修炼

关于会议规则，可以进一步学习《罗伯特议事规则》，西方人开会开了几百年，有成熟的规则可学。

04

领导篇

领导的作风是怎样的，公司的文化就是怎样的。

4.1

病灶：六种带头破坏规则的行为

很多公司，之所以开不好会，不是因为别的，首要原因是领导不重视。不仅不重视，还带头破坏规则：领导迟到、领导早退、领导不准备、领导一言堂、领导随意增加议题、领导急于表态。

关于会议的重要性不再赘述。糟糕的会议只会导致公司决策失误、执行不力、士气低迷、人心涣散，让领导威信扫地、让企业文化沦为口号。

记住：领导的作风是怎样的，公司的文化就是怎样的。
4.2

药方：真正厉害的领导怎么做

  • 带头遵守规则。 不小心破坏规则要自罚。
  • 不急于表态。 领导要最后表态，表态之前不动声色，表情“中立”。
  • 要敢于拍板，但不垄断话语权。 领导要拍板，还要垄断话语权，这是灾难；反过来，优柔寡断、不敢拍板，同样不行。该拍板的时候要拍板。
  • 拍完板就翻篇。 不要拍完板又讨论——那就无休无止。
  • 对会议成果负起责任。厉害的领导，会以实际行动，让会议活泼生动、卓有成效。他必须以身作则，树立标杆。
我认为，会议是发挥领导力的最佳时机。领导力是什么？是责任，是行动，是榜样。
05

治理篇

定期给会议体系做体检，并从组织上治本。

5.1

定期给会议体系做“体检”

德鲁克认为，任何组织都要“有计划地放弃”。我们必须定期对会议体系进行体检，砍掉赘肉，重新论证会议的必要性。

体检三问：

  • 会议总时长超了吗？→ 哪些会可以取消、哪些会可以合并？如何防止单次会议超时？
  • 会议取得预期成果了吗？→ 哪些行为妨碍了？
  • 如何优化和改进？
5.2

治本：会议过多是组织不健全的结果

还有一个隐蔽原因：公司的制度体系、组织架构不健全，导致会议很多。 组织架构不清晰，责权利不明确，那就只有通过会议来解决；普遍性问题，不去制定制度规则，而是每次都当做特殊问题去研究，那肯定就是会议泛滥了。

德鲁克说：会议过多，是组织不健全的表现。 治本三策：

  • 理清组织架构，明确责权利——能靠结构解决的问题，不应该靠会议解决；
  • 针对普遍性问题，制定制度流程——要靠制度流程解决的，不能反复开会研究；
  • 能够两人沟通、异步沟通解决的问题，不需要强行开会。
一句话：少开会、开好会、开出成果、开出精神。
附

教培机构「经营分析会」
开会指南

附

经营分析会的目的

  • 通过差异分析，挖掘机会，找出问题
  • 研讨、决定解决方案
  • 形成共识，明确行动方案
  • 沉淀集体经验（分校之间、部门之间交流经验，并沉淀下来）

召集人和参会人

召集人：由总经理召集

参会人：各分校校长、各部门总监

注｜差异分析：跟往年同期对比、跟预算/计划指标对比、跟兄弟部门/分校对比，分析差异产生的原因，挖掘机会，找出问题。
附

会议日程安排

  • 由行政部，在年度末提前排定下一年度会议日程，设置提前提醒
  • 会议日程确定后，在企业微信内及时共享，让其他参会人加入

各个月份的会议定位：（假设 经营年度为 7月至次年6月）

  • 4月、10月 → “季度经营分析会”，汇报季度经营情况
  • 1月 → “半年度经营分析会”，汇报半年度经营情况
  • 7月 → “年度经营分析会”，汇报全年度经营情况
  • 其他月份 → “月度经营分析会”，汇报月度经营情况
附

标准流程

  1. 回顾上次会议的议题
  2. 讨论本次会议的议题
  3. 各分校、部门汇报及交流
  4. 总校长总结
  5. 发出会议记录
附

会议准备

  • 参会人提前在群内发出汇报文件；
  • 汇报内容要求：讲重点、讲措施，不要过多讲细节、讲故事、讲个案
  • 会后各自复盘，持续优化汇报内容

议题的收集与筛选

  • 收集：各分校/部门把要提交的议题登记到“议题收集”栏；建议在会前一周的经营班子会（或管理层周会）先讨论确定要上会的议题
  • 筛选（由召集人把关）：简单议题不上会，群内直接解决；复杂议题必须基于事先公布、已基本成熟的行动方案再讨论；不讨论还停留在“想法”阶段、未经调研、没有方案的临时议题；不讨论重复议题（除非有一半参会人附议）
